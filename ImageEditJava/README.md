# 🖼️ ImageEditJava

A lightweight image editor built with Java Swing and Java2D — draw, annotate, and manipulate a canvas entirely from scratch.

> Part of [Java Projects](../README.md) — Bighiu Rares

---

## ✨ Features

| Tool     | Description                             |
| -------- | --------------------------------------- |
| Marker   | Thin freehand drawing (2px)             |
| Brush    | Thick freehand drawing (6px)            |
| Eraser   | Clears pixels on drag (10px)            |
| Text     | Click anywhere to add text              |
| Color    | Full color picker (JColorChooser)       |
| Flip H/V | Flips canvas horizontally or vertically |
| Zoom +/- | Scales canvas view in/out               |

---

## ▶️ Run

```bash
javac ImageEditJava.java
java ImageEditJava
```

---

## 🛠️ Skills

Java2D (BufferedImage, Graphics2D), MouseListener, MouseMotionListener, AlphaComposite, Swing layout
