# 🧮 CalculatorJava

A desktop calculator built with Java Swing.

> Part of [Java Projects](../README.md) — Bighiu Rares

---

## ▶️ Run

```bash
javac CalculatorJava.java
java CalculatorJava
```

---

## 📌 Notes

- Handles division by zero with an error message
- Supports decimals and square root
- Built with `GridLayout` and `ActionListener`
